# Photography Exposure Triangle Tuner

Adjust aperture, shutter speed, and ISO interactively to compute EV, see lighting conditions, and find equivalent exposure combinations.

## Features
- Three range sliders for aperture (f/1.0–f/32), shutter speed (1/4000s–30s), and ISO (100–102400)
- EV computed live with human-readable lighting label (e.g. "Sunny 16 rule", "Overcast")
- SVG exposure triangle diagram updates with current values
- Depth-of-field indicator (Very Shallow → Very Deep) based on aperture
- Grid of equivalent exposures at the same EV with different aperture/shutter combos

## Usage
Drag any of the three sliders to change aperture, shutter speed, or ISO. The Exposure Value (EV) and scene label update instantly. Scroll down to see a list of equivalent exposure combinations that achieve the same EV with different aperture and shutter pairings.
